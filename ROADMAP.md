# Roadmap

The repository grows by adding tested companion code without publishing the commercial book text.

## Near term

- Expand runnable examples for core language and type-system parts.
- Add framework-specific starter projects where maintenance cost is justified.
- Add production-oriented platform examples for later enterprise parts.
- Keep `docs/PARTS_INDEX.md` synchronized with every new code artifact.

## Quality gate

Every new runnable artifact should compile under strict TypeScript settings and include tests for important behavior.
