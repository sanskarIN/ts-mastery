## Part-folder convention

Each book part has exactly one `parts/part-XXX-*` navigation folder. Relevant part READMEs link directly to runnable projects instead of duplicating the same project source tree under multiple parts.

## Quality and publishing boundary

Run `npm run verify` before contributing. Keep public source code/tests/documentation in this repository, while keeping commercial publication files and complete chapter manuscripts outside the public repo.
