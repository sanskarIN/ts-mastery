# Build and Run Guide

The repository has one root toolchain. Individual companion projects do not need separate dependency installations.

## Script reference

### `npm run clean`

Deletes the generated `dist/` directory.

### `npm run check`

Runs the TypeScript compiler with `--noEmit`. Use it for a fast strict type check.

### `npm run build`

Cleans old output and compiles all `examples/**/*.ts` and `projects/**/*.ts` into `dist/`. Declaration files and source maps are generated by the root TypeScript configuration.

### `npm test`

Performs a clean build, recursively discovers every generated `*.test.js` file, and executes them with the Node.js test runner.

### `npm run verify:structure`

Checks curriculum folders, runnable-group structure, source/test presence, project naming, and exact `docs/code-catalog.json` coverage.

### `npm run verify:docs`

Checks local Markdown links and images so renamed or removed files do not silently break documentation.

### `npm run stats`

Prints current repository counts for parts, projects, examples, runnable groups, and source test files.

### `npm run verify`

Runs the complete local quality gate:

```text
structure → docs → strict type check → clean build → all tests
```

This is the command contributors and maintainers should run before pushing.

## Build output

With `rootDir` set to the repository root, source structure is preserved under `dist/`:

```text
projects/retry-policy/src/retry.ts
→ dist/projects/retry-policy/src/retry.js
```

The build also emits:

- `.d.ts` declaration files;
- `.js.map` source maps.

`dist/` is generated and should not be committed.

## Test discovery

The repository uses a Node script to recursively enumerate generated test files. This avoids platform-specific shell-glob differences and guarantees that nested project tests are not accidentally skipped.

If no compiled tests are found, the test script fails rather than reporting a false success.

## Running one compiled test during development

For a quick focused cycle:

```bash
npm run build
node --test dist/projects/typed-store/src/typed-store.test.js
```

Before committing, still run the complete `npm run verify`.

## CI

GitHub Actions executes the same verification command on the supported Node.js matrix. Local success is necessary, while CI provides a clean-environment check.
