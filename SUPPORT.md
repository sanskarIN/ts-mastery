# Support

## Code bugs

For a reproducible bug in the public companion code, open a GitHub bug report and include:

- affected project/path;
- Node.js version;
- command you ran;
- minimal expected vs actual behavior;
- minimal non-sensitive error output.

Before reporting, run:

```bash
npm install
npm run verify
```

## Documentation problems

Use the documentation issue form for broken links, unclear setup steps, stale API references, or navigation errors.

## New project ideas

Use the project-proposal issue form and explain the curriculum gap the project would fill. Project count alone is not a reason to add another project.

## Security issues

Follow [`SECURITY.md`](SECURITY.md). Do not publish actionable exploit details or real secrets in a public issue.
