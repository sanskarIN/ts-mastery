# Health Check Aggregator

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A typed health/readiness aggregator for service-reliability and platform-engineering exercises.

## Highlights

- named health checks
- `up`, `degraded`, and `down` states
- async check support
- thrown failures normalized into down results
- duplicate registration protection
- unregister support

Useful for SRE, backend services, readiness endpoints, workflow platforms, and production operations discussions.

```bash
npm run verify
```
