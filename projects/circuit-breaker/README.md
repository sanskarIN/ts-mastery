# Circuit Breaker

A compact resilience primitive that opens after repeated failures, blocks calls while unhealthy, and uses a half-open recovery probe after a reset window.

## Run

```bash
npm run verify
```

## Concepts

- failure thresholds
- open/closed/half-open states
- injected clocks
- production resilience patterns
- explicit error types
