# Cursor Pagination

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A small cursor-based pagination helper for REST/GraphQL/API exercises.

## Highlights

- opaque base64url cursors
- safe cursor decoding
- generic edge/connection types
- forward pagination using `first` + `after`
- deterministic `hasNextPage` and `endCursor`
- invalid-input protection

This project is useful for API design, GraphQL connection patterns, pagination contracts, and backend TypeScript practice.

```bash
npm run verify
```
