# Typed Command Bus

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A strongly typed command bus for practicing application boundaries, command/query style architecture, generic catalogs, handler registration, and async dispatch.

## Highlights

- command-specific input/output typing
- synchronous or asynchronous handlers
- duplicate-handler protection
- handler unregistration
- missing-handler errors

Use it as a compact companion for clean architecture, application services, and enterprise TypeScript design.
