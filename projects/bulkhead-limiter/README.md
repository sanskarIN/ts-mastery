# Bulkhead Concurrency Limiter

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A dependency-free bulkhead that caps concurrent work and optionally bounds queued work.

## Highlights

- configurable maximum concurrency
- optional queue capacity
- FIFO queued execution
- overload rejection when the queue is full
- deterministic tests using controlled promises

Useful for resilience, worker pools, API capacity protection, and workflow-platform exercises.

```bash
npm run verify
```
