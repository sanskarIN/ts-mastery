# Typed Store

A small dependency-free observable state primitive demonstrating generic state, immutable updates, typed subscriptions, and unsubscribe lifecycle.

Primary API: `TypedStore<T>`, `set`, `update`, `subscribe`, `value`, and `subscriberCount`.

Suggested curriculum mapping: Parts 16–18, 31–34.

Run from the repository root with `npm run verify`.
