# Typed Router

A compact framework-free router learning example for typed handlers, application context, duplicate-route protection, and stable 404 behavior.

Primary API: `TypedRouter`, `RouteRequest`, `RouteResponse`, and `RouteHandler`.

Suggested curriculum mapping: Parts 22, 25, 28–30, 46–50.
