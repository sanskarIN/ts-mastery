# Policy Decision Engine

A deterministic allow/deny rule engine with priorities, deny-on-tie behavior, and a default-deny posture.

Primary API: `decidePolicy`, `PolicyRule`, `PolicyDecision`, and `PolicyEffect`.

Suggested curriculum mapping: Parts 21–22, 97, 109–112.
