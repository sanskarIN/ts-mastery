# GeoJSON FeatureCollection Guard

A runtime `unknown`-boundary guard for GeoJSON FeatureCollections, Features, common geometry types, null geometries, and GeometryCollections.

The guard validates structural shape; it intentionally does not perform full coordinate-schema or CRS validation.

Primary API: `isFeatureCollection` plus exported GeoJSON types.

Suggested curriculum mapping: Parts 12, 80–84, 96.
