# Grid Spatial Index

A learning-oriented fixed-grid point index with insertion, removal, bounding-box querying, negative-coordinate support, and deterministic results.

Primary API: `GridSpatialIndex<T>`, `IndexedPoint<T>`, and `QueryBounds`.

Suggested curriculum mapping: Parts 82–95.
