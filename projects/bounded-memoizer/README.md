# Bounded Memoizer

A generic bounded memoization cache with LRU-style refresh behavior and support for `undefined` values.

Primary API: `BoundedMemoizer<K, V>` with `getOrCompute`, `has`, `clear`, and `size`.

Suggested curriculum mapping: Parts 8, 16, 20, 33.
