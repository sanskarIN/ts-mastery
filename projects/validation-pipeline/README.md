# Validation Pipeline

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A composable validation pipeline that demonstrates reusable rules, discriminated-union results, fluent APIs, and aggregation of multiple validation failures.

## Highlights

- generic validation rules
- fluent `add()` API
- all-error aggregation
- typed success/failure result
- reusable string validators
- no external runtime dependencies

Useful alongside API validation, domain modeling, safe boundary parsing, and clean architecture chapters.

npm run verify
