# Tile Coordinate Helpers

Dependency-free Web Mercator/slippy-map helpers for converting longitude/latitude to XYZ tile coordinates and calculating tile geographic bounds.

Primary API: `lonLatToTile`, `tileBounds`, `TileCoordinate`, and `GeographicBounds`.

Suggested curriculum mapping: Parts 75, 81–88.
