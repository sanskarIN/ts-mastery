# GeoJSON Guard

A runtime validation project for safely narrowing unknown input into typed GeoJSON Point Features before application code uses the data.

## Run

```bash
npm run verify
```

## Concepts

- `unknown` at trust boundaries
- user-defined type guards
- GeoJSON validation
- coordinate range checks
- safe narrowing before domain logic
