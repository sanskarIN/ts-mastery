# In-Memory Outbox Store

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A small outbox-pattern simulation for reliable messaging exercises.

## Highlights

- unique event IDs
- deterministic creation timestamps
- ordered pending-event reads
- publication marking
- safe snapshot returns
- duplicate protection

Use it to practice transactional-outbox concepts before integrating a real database or message broker.

```bash
npm run verify
```
