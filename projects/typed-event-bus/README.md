# Typed Event Bus

A dependency-free, strongly typed event bus demonstrating generic event maps, subscriptions, one-shot listeners, and safe payload routing.

## Run

```bash
npm run verify
```

## Concepts

- generic event maps
- typed payloads per event name
- unsubscribe functions
- one-time listeners
- deterministic unit tests
