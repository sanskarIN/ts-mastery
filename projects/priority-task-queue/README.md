# Priority Task Queue

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A stable priority queue for scheduler, worker, background-job, and orchestration exercises.

## Highlights

- higher numeric priority runs first
- FIFO ordering is preserved when priorities are equal
- generic payloads
- snapshot/peek/dequeue helpers
- deterministic tests

This project pairs well with asynchronous orchestration, queues, distributed processing, and workflow-platform topics.
