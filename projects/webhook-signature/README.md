# Webhook Signature Verification

A dependency-free HMAC-SHA256 signing and verification example using Node.js crypto and timing-safe comparison.

All tests use fake local secrets. Never commit production webhook secrets.

Primary API: `signWebhook` and `verifyWebhookSignature`.

Suggested curriculum mapping: Parts 21, 25, 47–50, 108–110.
