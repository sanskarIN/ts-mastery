# LRU Cache

> **📘 Complete TypeScript Full Mastery eBook:** **https://ramsandesh.gumroad.com**

A dependency-free generic least-recently-used cache for practicing `Map`, generics, encapsulation, eviction policy design, and deterministic tests.

## Highlights

- fixed positive capacity
- O(1)-style lookup/update behavior using `Map`
- reads refresh recency
- updates refresh recency
- automatic least-recently-used eviction
- strict TypeScript tests
