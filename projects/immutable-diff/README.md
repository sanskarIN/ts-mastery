# Immutable Record Diff

A shallow immutable diff/patch engine for plain records. It demonstrates discriminated unions, deterministic change ordering, immutable application, and simple change-set modeling.

Primary API: `diffRecord`, `applyRecordPatch`, and `RecordPatch`.

Suggested curriculum mapping: Parts 4, 16–18, 104–105.
