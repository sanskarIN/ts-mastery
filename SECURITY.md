# Security Policy

This repository contains educational companion code. Please report security issues privately rather than publishing exploit details in a public issue when a report could put users at risk.

Do not commit:

- API keys or access tokens
- passwords or private keys
- production connection strings
- personal/private datasets
- authentication cookies or session material
- proprietary source code you do not have permission to publish

Examples should use fake values, local fixtures, or environment-variable placeholders.
